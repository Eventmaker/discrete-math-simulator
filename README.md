## 🚀 Що всередині симулятора?

### 1. 📊 Множини та діаграми Ейлера-Венна
* **8 повноцінних операцій над множинами**:
  * Об'єднання ($A \cup B$) з формулою включень-виключень.
  * Переріз ($A \cap B$) з автоматичним визначенням диз'юнктності ($A \cap B = \emptyset$).
  * Різниці ($A \setminus B$ та $B \setminus A$).
  * Симетрична різниця ($A \mathbin{\triangle} B$, операція XOR з «вибитим центром»).
  * Доповнення ($A'$ та $B'$ відносно універсуму $U$).
  * Предикатний тест включення підмножини ($A \subseteq B$, власна строга підмножина $A \subset B$, рівність $A = B$).
* **Математична точність та SVG-маскування**:
  * Топологічні зони ізольовані через `<mask id="outside-mask">` — доповнення універсуму не витікає всередину виключених кіл.
  * Гібридний числовий та природний алфавітний парсер: коректно обробляє як числа більше 9 (наприклад, `10, 20, 100`), так і букви (`a, b, x, y`).
  * Динамічний універсум $U$: автоматично синхронізується та розширюється при введенні нових елементів, зберігаючи аксіоми теорії множин.
* **Швидкі навчальні пресети**: перетин, диз'юнктні множини, власна підмножина, рівні множини, буквені множини, великі числа.

### 2. 🕸️ Бінарні відношення та орієнтовані графи
* **Інтерактивна матриця суміжності $M_\rho$ ($4 \times 4$)**: клікайте по комірках для миттєвої перебудови графа.
* **SVG-візуалізатор графа**:
  * Вершини у вигляді неонових вузлів з анімованими мітками.
  * Направлені дуги (криві Безьє) та самопетлі (кубічні сплайни) при $a \rho a$.
* **Автоматична діагностика 5 фундаментальних властивостей**:
  * Рефлексивність / Антирефлексивність.
  * Симетричність / Асиметричність / Антисиметричність.
  * Транзитивність (через логічний добуток булевих матриць $M^2 \le M$).
* **Класифікація відношень та факторизація**:
  * Визначення відношення еквівалентності та розбиття на класи еквівалентності $A / \rho$.
  * Відношення часткового та лінійного порядку.
* **Панель інструментів швидкого редагування**: заповнення діагоналі, симетризація, транзитивне замикання.

### 3. 🎲 Комбінаторний калькулятор та дерево рішень
* **Інтерактивне дерево рішень (Decision Tree)**: покроковий алгоритм розпізнавання правильної комбінаторної конфігурації.
* **Майстер підбору за 3 питаннями**:
  1. Чи всі $n$ елементів входять у сполуку?
  2. Чи має значення порядок елементів?
  3. Чи дозволені повторення елементів?
* **Розрахунок усіх 5 базових конфігурацій**:
  * Перестановки без повторень: $P_n = n!$
  * Перестановки з повтореннями: $P_n(k_1, k_2, \dots, k_m) = \frac{n!}{k_1! \cdot k_2! \dots k_m!}$
  * Розміщення без повторень: $A_n^k = \frac{n!}{(n-k)!}$
  * Розміщення з повтореннями: $\overline{A}_n^k = n^k$
  * Комбінації без повторень: $C_n^k = \binom{n}{k} = \frac{n!}{k!(n-k)!}$
  * Комбінації з повтореннями: $\overline{C}_n^k = \binom{n+k-1}{k}$
* Покроковий арифметичний розпис факторіалів та захист від переповнення.
